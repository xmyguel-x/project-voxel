O que há nesta release

Project Genesis 32X — patch nativo do PicoDrive 2.05 que transforma o quadro 2D numa cena 3D de voxels. 21 opções de render: voxel, cor, luz, ambiente, profundidade, floor, scanlines, paleta e mais.
Dois modos no mesmo core — o núcleo Project Genesis roda o Genesis pelo caminho GPGX e o 32X pelo PicoDrive. As opções project_genesis_* são compartilhadas pelos dois.
Retro8 Voxel — wrapper separado que carrega o core PICO-8 via dlopen() e reconstrói a cena 128×128 em 3D, com z-buffer e carcaça de console com botões que afundam.
Patch e script inclusos — project-genesis-32x.patch aplica sobre o PicoDrive na commit 1890c29, e build_termux_32x.sh compila o .so de Android no Termux.
03

Instalando

Baixe o core da sua plataforma

Windows: project_genesis_32x_libretro.dll. Linux: project_genesis_32x_libretro_linux_x86_64.so. Android: o .so é gerado no Termux pelo script incluso.

Copie para a pasta de cores

Windows: %APPDATA%\RetroArch\cores. Linux: ~/.config/retroarch/cores. Android (Termux): ~/retroarch/cores.

Copie o arquivo .info

project_genesis_32x_libretro_android.info na mesma pasta, com o nome do core — é ele que registra a identidade Project Genesis 32X no RetroArch.

Reinicie o RetroArch

O core aparece como Project Genesis 32X. As opções de render ficam no menu Core Options.
